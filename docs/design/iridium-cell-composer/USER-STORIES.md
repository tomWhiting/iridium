# Iridium-Cell-Composer — User Stories

## Norn host integrator — host

**S1.** As a host integrator, I can rely on one Unicode cell geometry for visible text, caret and pointer positions.

**S2.** As a host integrator, I can edit wrapped Unicode text and keep every undo branch through resize.

**S3.** As a host integrator, I can embed the composer in my rectangle while retaining ownership of terminal and focus.

**S4.** As a host integrator, I can adopt the composer with proof that existing renderer and input paths still behave as before.
